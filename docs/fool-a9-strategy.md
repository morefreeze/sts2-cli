# 愚者 A9：牌效纠错与构筑策略（2026-11-19）

本轮只改愚者的选牌、商店牌价估值和升级目标；战斗保持现有 Solver，事件和路线策略不改。以下系数是启发式规则，不是训练得到的胜率模型。

## 败局证据

用户指出的前 24 局 A9：0 胜，20 局死于 Boss。根据原始 `.run` 的房间记录，第一幕 Boss 13/22 通过，第二幕 5/13 通过，第三幕 0/3 通过。另有 4 局死于非 Boss；不是 24 局都到达了 Boss。

运行开始后旧策略又结束一局 A9，仍败于第一幕 Boss。该局属于旧策略，不计为本次改动的实战结果。

旧评分没有任何愚者评级/词条数据；输入还包含 `SORROWFUL_STRIKE.description` 这样的未翻译键名。已确认：

- `Cards` 被一概算作抽牌，导致悲伤斩击、玩笑、狂喜、合奏、叽吟唱等误估。
- 下回合/条件回能被当作即时无条件回能，尤其高估史诗回收、叽休息。
- 拉伸、瞄准、条件多段、旋律降费和按旋律数量结算的效果没有被完整计算。
- 大牌组中，铁甲战士力量/消耗/壁垒规则对愚者普通牌统一扣 3 分，连新角色核心能力也无法识别。
- 升级目标按升级前牌强度排序，没有计算升级的费用、抽牌、每段伤害和持续收益差值。

## 实现

`agent/fool_scoring.py` 使用独立的效果/配合评分，覆盖愚者牌事实表。实际观察到的动态数值优先于版本默认值，状态不被修改。

- 明确区分真实抽牌、检视后选择、悲伤生成和每回合触发；条件/延迟收益折算，不视作即时保证收益。
- 计算固定多段、旋律支持的额外段数、旋律降费和哇交响的牌组计数。旋律在战斗中逐步形成，默认折算为最终支持数量的 75%，而非假定第一回合全部存在。
- 拉伸按以后能转为格挡的期望计值；瞄准对多段箭的收益、箭袋缓解箭矢竞争进入配合分。
- 歌之道要求啾，暴烈和弦要求哇，催眠曲要求三类，失落鲁特琴要求至少一种旋律。缺触发条件时不会按已成型引擎估值。
- 悲伤代价与悲伤收益卡双向识别，持续能力重复有代价。避免把所有射击牌都视作同一手可连续使用。
- 愚者奖励不再套铁甲战士流派扣分及旧卡 ID 预测器；trace 保留基础分与实际配合差值，精确求和。
- 篝火升级按前后差值比较，保留外色/无色牌参选，记录全部合法候选的升级分数。
- 新事实表加入 bundle 白名单、Git 例外及评分数据哈希；其他角色黄金语料保持原选择。

## 离线验收与局限

冻结 `advisor_trace` 中已执行的决策，按 run + 完整 state 去重。

| 检查 | 基线 | 新策略 |
| --- | --- | --- |
| 本地 A9：304 个选牌点、26 个种子 | 304/304 复现日志选择 | 203/304 发生改变 |
| 外部 A10：独立 40 局、693 个奖励点，与作者模型选择一致 | 204/693，29.4% | 247/693，35.6% |
| 外部模型信心 ≥90% 的 509 点 | 153/509，30.1% | 188/509，36.9% |

外部 40 局按 replay 文件名 SHA256 排序取前 40，不按胜负筛选。输入以该项目公开 vocab、候选和牌组重建；外部游戏版本是 v0.113.0，本机事实表为 v0.113.1，因此这不是同版本模拟结果。没有把模型选择当作反事实胜负标签，也没有据此声称新策略胜率提高。

本地变化中，原先 26 次选悲伤斩击、20 次选玩笑、7 次选叽休息都改为其他选项；多次原先跳过的箭术、根系、歌之道、催眠曲和秘神形态进入候选。新策略也改变了普通攻击选择，不能把所有变化都解释为收益。

本机旧 Headless CLI 已实测返回 `Unknown character: Fool`；`play_full_run.py` 也只支持前五角色。因此本轮无法合法地给出愚者同状态 Solver 分叉胜负、Boss 胜率或全局胜率提升。需先单独完成 v0.113.1 Fool Headless 兼容，再做配对种子实战。当前实机远征继续运行，新版本的实战记录必须和旧版本、跨版本混合局分开。

`tools/eval_fool_drafting.py` 可复现本地选择回放，输出输入/策略/数据哈希、行为环境与逐点分数，明确标记 `outcomes_evaluated=false`。
